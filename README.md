# android-lab02 网络安全对比实验
## 实验目标
掌握Android网络权限配置，理解network_security_config网络安全配置，对比HTTP与HTTPS请求访问差异。

## 运行方式
1. Android模拟器/真机打开APP
2. 点击【HTTP请求】访问 http://httpbin.org/get?room=A203
3. 点击【HTTPS请求】访问 https://httpbin.org/get?room=A204
4. 在界面查看请求响应结果

## 接口地址
- HTTP地址：http://httpbin.org/get?room=A203
- HTTPS地址：https://httpbin.org/get?room=A204

> HTTP仅用于教学对比，实际服务优先 HTTPS
